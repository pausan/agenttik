# UI

Single page, vanilla JS, no build step. Served from `go:embed`. Streaming over
`EventSource`.

## Layout

```
┌────────────┬──────────────────────────────┬──────────────┐
│ Projects   │ [Conversation][file.go][x]   │ Stats        │
│ Sessions   │                              │ Changed      │
│            │  transcript                  │ Tree         │
│ ...list... │                              │              │
│            ├──────────────────────────────┤  ...panel... │
│            │ prompt        [model][effort]│              │
└────────────┴──────────────────────────────┴──────────────┘
```

**Left — Projects tab:** project name, folder underneath in small grey, then the
titles of its last 5 sessions, one per line. Clicking a title opens it.

**Left — Sessions tab:** running sessions first, then everything touched inside
the window (1d / 3d / 7d / 1mo, default 3d), across all projects. Each row is the
session title with project name and folder in small grey below. A text filter at
the top matches title, project name and path.

**Centre:** a tab strip. The first tab is the conversation and cannot be closed;
opening a file from the right panel adds a closable tab. The prompt box sits at
the bottom with two pickers, model and effort. Starred combinations appear first,
above a separator; the star toggle is next to the pickers.

**Right:** `Stats | Changed | Tree`.
- Stats — model, effort, permission mode, turn count, input/output/cache tokens,
  cost, total agent time, session started.
- Changed — `git status --porcelain` in the project folder, edited files only.
- Tree — the repo's files, `.git` and gitignored paths excluded.

## HTTP API

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/providers` | providers, models, efforts, availability |
| GET | `/api/projects` | projects with last 5 session titles |
| POST | `/api/projects` | `{name, path}` |
| DELETE | `/api/projects/:id` | |
| GET | `/api/sessions` | `?window=3d&project_id=&q=` |
| POST | `/api/sessions` | `{project_id, provider, model, effort, permission, title}` |
| GET | `/api/sessions/:id` | session, messages, stats |
| POST | `/api/sessions/:id/messages` | `{prompt}` — starts a turn |
| POST | `/api/sessions/:id/stop` | cancels the running turn |
| GET | `/api/sessions/:id/stream` | SSE of live events |
| GET/POST/DELETE | `/api/stars` | starred model+effort |
| GET | `/api/projects/:id/tree` | file tree |
| GET | `/api/projects/:id/changes` | changed files |
| GET | `/api/projects/:id/file?path=` | file contents |

Every path parameter under `/api/projects/:id/` is resolved against the project
root and rejected if it escapes it. The server binds to `127.0.0.1` by default and
has no authentication — it is a local tool.
