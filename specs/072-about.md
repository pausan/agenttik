# About

Settings → About shows the project name, the running server version from
`S.instanceInfo` (`GET /api/version`), creator Pau Sánchez, copyright © 2026
Pau Sánchez, and the full MIT license bundled from the repository’s `LICENSE`.
It also contains the Troubleshooting area, which lists and manages local error
reports. If the version is unavailable, the pane says so. Development builds
report `dev`.

The settings filter matches About, the project name, creator, version,
copyright, license, MIT, Troubleshooting, Last Errors, bug report and trace.
The pane is below Help and is available in desktop and browser views.
